# Social Media Content Performance Analysis

This project focuses on analyzing historical social media performance data to identify content patterns and predict high-performing social media content using Machine Learning.

The project involves data cleaning, exploratory data analysis (EDA), feature engineering, and predictive modeling using the **XGBoost algorithm**. The model achieved **78.12% accuracy** in classifying high-performing content.

Additionally, a Streamlit-based application was developed to enable users to test different content characteristics and obtain data-driven recommendations to support social media content strategy.

### Key Features
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Predictive Modeling using XGBoost
- High-Performing Content Classification
- Interactive Prediction Dashboard using Streamlit

### Tools & Technologies
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- XGBoost
- Streamlit
- Google Colab

### Project Objective
To leverage historical social media data and Machine Learning techniques to support data-driven content planning and improve social media performance.
